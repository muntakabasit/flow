## What to read before changing the interface

1. Read the [human-directed Flow product lock](https://github.com/muntakabasit/flow/issues/1#issuecomment-7166799703) and preserve its runtime and private-source boundaries.
2. Read the relevant [DAWT Design register entry](dawt-design/README.md) and its original source/status.
3. Read the owning project's current authorised task and test fixture, if available in your own authorised environment. Do not assume a file can be read merely because it is referenced publicly.
4. Return the human-experience question, what is confirmed and unknown, one bounded design move, tests, source privacy and STOP. No inferred implementation admission.

Publishing an assessment on GitHub does not grant access to personal email, private study excerpts, OAuth, the existing interpreter runtime or production code mutations. Design quality must be shown on a real user task and the actual relevant device, not inferred from an attractive static preview.
